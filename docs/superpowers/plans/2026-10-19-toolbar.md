# Toolbar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A floating Material-style pill next to the phone window with Paste, Copy (disabled), Home, App switcher, Natural-scroll toggle and Collapse.

**Architecture:** Pure-logic modules (typing table, pill layout/state) are unit-tested; `app.py` owns the three pygame windows (phone, pill, tooltip) and wires pill actions to the existing `Controller`/`Pointer`/link. Keyboard output goes through one paced queue so pastes and live typing never interleave.

**Tech Stack:** pygame-ce 2.5 `pygame.Window` (multi-window, borderless, utility), bundled Material Symbols Rounded subset TTFs, existing links/mouse modules.

**Spec:** `docs/superpowers/specs/2026-10-19-toolbar-design.md`

## Global Constraints

- Linux (Fedora/Wayland via SDL's X11 driver) and macOS; no new runtime dependency.
- Palette (spec): pill `#dfe6f1`, icon `#3a4656`, hover overlay `(58,70,86)` at 10%, active fill `#b9cbe8` / icon `#0f2a4d`, disabled `#a9b3c1`, separator `#c6cfdb`, tooltip `#303034` / text `#f2f0f4`.
- Pill height = 80% of phone window height, vertically centred, 6 px gap, right side (left if no room). Button diameter ≤ 40 px. Collapse chevron ≈ 60% of a button.
- Settings remain CLI flags; the bar only changes live state.

## Findings this plan relies on (verified 2026-10-19)

- Pill window follows the main window while dragging and resizing on the user's Fedora (WINDOWMOVED/RESIZED → set `pill.position`/`size`). SDL runs on XWayland (`driver x11`).
- Rounded pill ends are not possible (X Shape is reset under XWayland; native Wayland can't position windows): **square-cornered pill window**, user decision.
- Cmd+H does not go Home on iPhone 8 / iOS 16 → Home and App switcher use AssistiveTouch device-button mapping: mouse button 2 = Home, button 3 = App Switcher (user sets it once).

## Review Focus

1. Paste of text with characters outside the US table (`è`, emoji, `\r\n`) → those are skipped and counted, `\r\n` types one Enter, nothing else breaks. (Task 1 test)
2. Live typing while a long paste is running → typed keys come after the paste, never interleaved into it. (Task 2 test)
3. Window shrunk very small → buttons shrink but never overlap and never go below a usable minimum (16 px); pill never taller than the window. (Task 3 test)
4. Mouse leaves the pill while a tooltip is showing / pill collapses → tooltip hides. (Task 4 test)
5. No mouse backend (`--mouse none`) → Paste/Home/Apps disabled with the "needs --mouse ble or esp32" tooltip, clicking them does nothing. (Task 3 test)

### Task 3: Pill layout + state (pure)

**Files:**
- Create: `scrcrappy/toolbar.py`
- Test: `tests/test_toolbar.py`

**Interfaces:**
- Produces:
  - `@dataclass Button(id: str, icon: str, tip: str, enabled: bool = True, toggled: bool | None = None, small: bool = False)` (`toggled is None` = not a toggle). `icon` = Material Symbols codepoint char.
  - `buttons(has_input: bool, natural: bool) -> list[Button | None]` (`None` = separator) in spec order: paste, copy, None, home, apps, None, natural, None, collapse(small). Copy always `enabled=False`, tip = spec text. Without input: paste/home/apps disabled, tip "Needs --mouse ble or esp32".
  - `pill_rect(main_pos, main_size, desktop_size) -> tuple[int, int, int, int]` (x, y, w, h): h = round(0.8 × main h), centred; x right of main + 6, or left (`main_x - 6 - w`) if it would leave the desktop.
  - `layout(items: list[Button | None], height: int) -> tuple[int, list[tuple[Button, pygame.Rect]]]`: returns pill width and button hit-rects; diameter = clamp((height − padding) / slots, 16, 40), small buttons 0.6×, separators take 1/3 slot.
  - `TAB = (8, 48)` collapsed tab size.

**Interfaces:**

- `class Pill(main: pygame.Window, actions: dict[str, Callable[[], None]], items: list[Button | None])`: owns pill + tooltip windows; `follow()` (re-place after main moved/resized/shown/hidden), `handle(event) -> bool` (consumes events whose `event.window` is pill/tooltip), `draw()`; state: `collapsed`, `pinned`, `hover`, tooltip after 500 ms hover. Collapsed → pill window resized to `TAB`, centred; WINDOWENTER on it → expand; WINDOWLEAVE → collapse unless pinned; chevron click toggles `pinned` (icon chevron_left when pinned/open, chevron_right when collapsible). After any click: `main.focus()`.
- `app.run(...)` becomes window-based: main `pygame.Window("scrcrappy", resizable=True)` instead of `display.set_mode`; events with `event.window == main` go to Controller as today; pill actions: paste → `controller.paste()` (skipped > 0 → print `skipped N characters (US layout, ASCII only)` to stderr), home → `pointer.click(2)`, apps → `pointer.click(4)`, natural → flip `controller.natural_scroll` and button `toggled`, copy → none.
- `Pointer.click(buttons_mask: int)`: queued like `button()`: press with mask, then release; no move.
